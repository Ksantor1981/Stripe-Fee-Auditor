# Marketing page i18n pattern

## Message files

- **Source of truth (English):** `messages/pages/en.json` — generated by `node scripts/extract-pages-en.mjs`
- **Locales:** `messages/pages/{es,de,fr,hi,ru}.json` — same structure, generated by `python scripts/translate-pages-locales.py`
- **Merged at runtime** in `lib/i18n/load-messages.ts` via `deepMergeMessages`

Structure:

```json
{
  "seo": { "stripeFeesReport": { ... }, "stripeFeeCalculator": { ... } },
  "blog": { "howToReduceStripeFees": { ... }, "whyIWontConnectMyStripeAccountToThirdPartyTools": { ... } }
}
```

## Reference implementation: `stripe-fees-report`

1. **Copy in JSON** — flat keys under `seo.stripeFeesReport` (hero, grids, steps with link fragments, FAQ, CTA).
2. **Content component** — `components/marketing/StripeFeesReportContent.tsx` loads `getTranslations("seo.stripeFeesReport")` and renders the layout.
3. **Page shell** — `app/stripe-fees-report/page.tsx` uses `stripeFeesReportMetadata()` for SEO + FAQ JSON-LD; renders `<StripeFeesReportContent />`.

### Adding another SEO page

1. Add extraction block in `scripts/extract-pages-en.mjs` (or extend an existing block).
2. Run `node scripts/extract-pages-en.mjs` and `python scripts/translate-pages-locales.py`.
3. Create `components/marketing/{PageName}Content.tsx` mirroring `StripeFeesReportContent.tsx`:
   - Types for the copy shape
   - `getTranslations("seo.{camelKey}")`
   - Presentational JSX only (no hardcoded English)
   - Export `{page}Metadata()` returning `{ title, description }` from `metaTitle` / `metaDescription`
4. Slim `app/{route}/page.tsx` to metadata + structured data + `<MarketingShell><{Page}Content /></MarketingShell>`.

### Blog & privacy articles

Copy lives under `blog.*` (fee posts and privacy articles share the same namespace). Pages use `BlogArticleContent` with camelCase keys from `lib/i18n/blog-slug-map.ts`.

## Scripts

```bash
node scripts/extract-pages-en.mjs          # refresh en.json from page.tsx sources
pip install deep-translator
python scripts/translate-pages-locales.py  # regenerate locale files
```
